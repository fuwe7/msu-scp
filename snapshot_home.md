# SNAPSHOT: Главная страница scpfoundation.net
URL: https://scpfoundation.net/

## Структура блоков (сверху вниз)
1. Статья недели — краткая цитата/тизер + ссылка
2. Статья дня — ссылка на выбранную статью
3. Новые SCP-объекты русского филиала — список свежих статей
4. Новые рассказы русского филиала — список свежих рассказов
5. Новые переводы SCP-объектов — список свежих переводов
6. Футер: версия страницы, дата последней правки
