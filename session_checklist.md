# session_checklist.md — что делать перед каждой новой сессией (для человека)

1. Открой STATE.md из результатов прошлой сессии.
2. Прочитай раздел "ЧТО ПРИЛОЖИТЬ В СЛЕДУЮЩУЮ СЕССИЮ" — приложи ровно эти файлы, ни больше ни меньше.
3. Прочитай раздел "КАКОЙ ПРОМПТ ИСПОЛЬЗОВАТЬ" — скопируй текст указанного batch_N.md файла целиком как сообщение.
4. Если STATE.md говорит "ПРОМПТ НЕ ГОТОВ" — попроси меня (в чате с Perplexity) сгенерировать следующий batch_N.md перед стартом сессии в Hermes.
5. Отправь промпт + приложенные файлы новой сессии Hermes.
6. После завершения — скачай обновлённые site-map.md, codex.md, progress_log.md, STATE.md из результатов сессии для следующего раза.
