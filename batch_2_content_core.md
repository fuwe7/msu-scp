## Алгоритм на каждую target_page

1. `planner` проверяет статус страницы и её зависимости в `site-map.md`.
2. Делегируй задачу:
   - `Content-page` → `content_executor`.
3. Дождись черновика.
4. Запусти проверяющие роли:
   - `Content-page` → `lore_keeper`, `immersion_checker`, `gap_analyzer`.
5. Передай все замечания `reviewer`.
6. `reviewer` запускает собственный чек-лист:
   - Item Number / ЛП-XX / АН-XXXX уникальны (сверка с `codex.md`);
   - есть Object Class (для объектов), соответствующий описанной угрозе;
   - есть Special Containment Procedures (для объектов);
   - есть Description;
   - есть Addendum / interview log / experiment log (если применимо по лору);
   - тон каноничный (сухой, бюрократический, без современного жаргона);
   - есть теги и связь с Hub-страницей;
   - нет противоречий с ранее одобренными страницами (`codex.md`);
   - нет лорных фактов, не подтверждённых `lore_keeper`;
   - есть перелинковка (см. также / связанные объекты).
7. `reviewer` делит замечания на `BLOCKING` и `NICE-TO-HAVE`, `round_counter += 1`.
8. Если есть `BLOCKING` и `round_counter < 3`:
   - верни единый список замечаний `content_executor`;
   - исправляй только затронутые разделы;
   - повтори проверку (шаги 4–7).
9. Если `round_counter == 3` и `BLOCKING` остались:
   - `reviewer` переводит их в `known limitations`;
   - фиксирует список в конце страницы или в `progress_log.md`;
   - одобряет страницу.
10. После одобрения:
    - обнови `site-map.md` (статус страницы → `approved`);
    - обнови `codex.md` (новые термины, занятые номера, новые сквозные ссылки, summary страницы 3–5 строк);
    - добавь строку в `progress_log.md`:
      `Content: [имя] — round_counter: X — known limitations: [список или "нет"] — статус: одобрено`.
11. Перейди к следующей `target_page` без ожидания человека.

## Материал для ветки G (org-info) — уже согласованные факты, не изобретать заново

- Научное подразделение: КИПВП — Корпус изучения пространственно-временных перемен
- Отделы (из заголовков документов лора): Отдел исследования лиминальных пространств; Научный отдел теории лиминальных пространств; Архив научных наблюдений
- Высший орган: Совет К.И.П.П.
- Уровни доступа: подтверждены АЛЬФА-4 и АЛЬФА-5 в лоре — оформить как шкалу от АЛЬФА-1 (низший) до АЛЬФА-5 (высший), не придумывать промежуточные уровни с деталями, только назвать шкалу
- Тон: сухое организационное предупреждение об ограничении доступа, без прямого раскрытия миссии
