# SNAPSHOT: Hub-страница списка объектов (scp-series)
URL: https://scpfoundation.net/scp-series

## Структура блоков
1. Условные обозначения (легенда) — цветовая маркировка класса объекта:
   - Не назначен/нейтрализован
   - Безопасный
   - Евклид
   - Кетер
   - Таумиэль
   - Нестандартный класс
2. Разбивка на секции по сотням номеров (001-099, 100-199, ... 900-999)
3. В каждой секции — построчный список: "SCP-XXX — Название" (название = ссылка на статью)
4. Ссылки на смежные списки в конце: "Список аномальных предметов", "Список аномальных явлений", "Список необъяснённых локаций"

## Заметки для site_architect
- Это шаблон hub-template.html. Ключевой элемент — цветовая легенда класса + построчный список с сортировкой по диапазону ID.
- Для MSU-SCP: аналог — Hub всех объектов лора, сгруппированных по категории/факультету/корпусу.
