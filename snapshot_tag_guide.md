# SNAPSHOT: Система тегов (сокращённо, для ориентира)
URL: https://scpfoundation.net/tag-guide

## Категории тегов
1. **Класс объекта** (только для SCP-объектов, ровно один): безопасный / евклид / кетер / таумиэль / аполлион / архонт / нейтрализованный / списан / обоснованный
2. **Тип статьи**: объект / рассказ / досье / личное_дело / лор / хаб / дополнение
3. **Связующие теги**: привязка к конкретным организациям, персонажам, локациям, циклам (аналог сквозных ссылок в codex.md)
4. **Теги характеристик аномалии**: пространственный / временной / когнитивная_угроза / изменение_реальности / биоугроза и т.д. — описывают СВОЙСТВА, а не тип статьи

## Заметки для content_executor / codex.md
- Для MSU-SCP нужен свой упрощённый список тегов характеристик под ваш лор (не копировать чужую систему буквально, а адаптировать под реальные аномалии из msu-scp-lore.md).
- Тег класса объекта — ровно один на статью, обязателен для gap_analyzer/reviewer чек-листа.
