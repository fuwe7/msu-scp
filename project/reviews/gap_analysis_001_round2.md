# Gap Analysis (Round 2) - SCP-MSU-001
Для роли: reviewer

1. Написано про «Класс опасности: Кетер». Отсутствует: лорный уровень опасности для сектора «Зверинец» — «Средний» (или соответствующий ему класс «Евклид»). Почему это важно: лор (msu-scp-lore.md) прямо устанавливает опасность сектора Зверинец как «Средний». Использование класса «Кетер» (обозначающего крайнюю сложность содержания и высокую угрозу) противоречит этому указанию.

2. Написано про аномальные сущности (SCP-MSU-001). Отсутствует: упоминание лорного обозначения «Объект-01». Почему это важно: согласно msu-scp-lore.md, в Зверинце фиксировались признаки присутствия именно «Объекта-01». Без упоминания этого обозначения (например, как внутреннего кода К.И.П.П. или предыдущего названия) теряется прямая связь статьи с исходным лором.

3. Написано про «Уровень доступа: 4». Отсутствует: использование формата К.И.П.П. для уровней допуска (например, «АЛЬФА-4» или «АЛЬФА-5»). Почему это важно: использование стандартного формата SCP («Уровень 4») вместо лорной системы допусков «АЛЬФА-X» разрушает уникальную корпоративную стилистику документации Комитета.
